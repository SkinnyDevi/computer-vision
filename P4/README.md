# Práctica 4 de Visión por Computador

> Autores: Félix Miguel Velásquez, Cristina Santana Martín

Este proyecto desarrolla la detección y seguimiento de objetos mediante detectores como YOLO y RT-DETRv2 para el entrenamiento y 
detección de matrículas de vehículos, junto a la evaluación del texto de las matrículas mediante OCR, y la evaluación de tecnologías
tradicionales y modernas en reconocimiento de carácteres.

- **[Práctica 4b: Reconocimiento de Carácteres y Evaluación de Tecnologías](./P4b)**
